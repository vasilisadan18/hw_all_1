## Введение
В данном проекте исследуются методы анализа физиологических сигналов (в частности, данных с акселерометров) для определения активности человека.  
Подобные подходы применяются в смарт-часах и фитнес-браслетах для распознавания действий (ходьба, бег, сон и др.) и оценки состояния здоровья.

## План реализации
- Сбор данных и EDA - поиск и обработка датасетов из интернета (преимущественно с kaggle)
- Использование линейных моделей ML для решения поставленной задачи
- Использование нелинейных моделей ML, feature-engineering и выбор лучшего ML-решения
- Создание Telegram бота с имплементацией лучшего ML-решения
- Внедрение DL-модели
- Доработка задачи: улучшение сервисной части по обратной связи от команды курса П.Р.; тюнинг DL-моделей и выбор лучшего решения overall
